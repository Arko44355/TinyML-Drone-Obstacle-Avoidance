SECTION 01 // MOTIVATION & PROBLEM

Edge Robotics Challenges & Resource Constraints

Traditional Drone Flight Limits

  • High Power Consumption: GPU/Companion Computers drain flight battery rapidly.
  • Cloud Latency Lag: Offloading sensor data introduces unpredictable 50-200ms latency spikes.
  • Deep Model Overhead: CNNs exceed MCU SRAM capacity (500KB+ required).

The Proposed TinyML Solution

  • Sub-Microsecond Latency: Decision Tree (Depth 5) computes steering in just 1.2µs.
  • Ultra-Low Memory Footprint: Fits into 52 Bytes RAM and 0.5 KB Flash.
  • Deterministic Safety: Zero cloud dependency with 100% autonomous edge execution.
