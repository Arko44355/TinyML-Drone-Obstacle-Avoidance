01. Problem Statement

The GPS-Denied Mobile Robot Navigation Challenge

Traditional Edge Compute Limits

  • High Electrical Drain: GPU companion boards consume excessive battery power.
  • Heavy Memory Overhead: DNN interpreters exceed MCU SRAM limits.
  • High Latency: Runtime inference delays increase collision risks at speed.

Proposed TinyML 2WD Robot Solution

  • Ultra-Low Power: Operates on STM32F401 Black Pill MCU.
  • Zero Interpreter Dependency: Compiled standard C-header (`tinyml_model.h`).
  • Sub-Microsecond Latency: Differential PWM motor steering calculated in 1.2 µs.

03. Algorithm & Deployment

Decision Tree C-Code Header Export

Steering Decision Branches

The trained model directly translates spatial range array inputs into instantaneous steering classes:

  • Class 0: Move Straight
  • Class 1: Turn Left
  • Class 2: Turn Right
tinyml_model.h Pure C Header 
int predict_rover_action(const float sensor[5]) {
  if (sensor[2] <= 0.9997f) {
    if (sensor[1] <= 4.7937f) {
      if (sensor[4] <= 4.8878f) return 2; // Right
      else return 1; // Left
    }
  } else {
    if (sensor[1] <= 0.7997f) return 2;
    else if (sensor[3] <= 0.7997f) return 1;
    else return 0; // Straight
  }
}

06. Hardware Implementation

2WD Robot Car STM32 Pinout & Power Schematic

Power Distribution

  • 7.4V Li-ion (+) → L298N 12V & Buck Regulator
  • GND (-) → Common System Ground

Sensor Array Bus

  • PB6 (SCL) → PCA9548A Mux SCL
  • PB7 (SDA) → PCA9548A Mux SDA

Motor PWM Outputs

  • PA0, PA1 → Left Motor PWM Driver
  • PA2, PA3 → Right Motor PWM Driver
